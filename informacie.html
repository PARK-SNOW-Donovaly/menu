02 · OCHRANA SÚKROMIA

Aké údaje web spracúva

Táto stránka slúži na zobrazovanie jedálnych a nápojových lístkov. Neobsahuje používateľské účty, kontaktný formulár, rezervácie ani platby a od návštevníkov nevyžaduje osobné údaje.

Pri návšteve môžu byť z technických a bezpečnostných dôvodov spracované bežné prevádzkové údaje, napríklad IP adresa, typ prehliadača, čas požiadavky a navštívená adresa. Tieto údaje môže spracúvať poskytovateľ hostingu GitHub Pages.

03 · NASTAVENIA WEBU

Vzhľad a jazyk

Web si môže v lokálnom úložisku prehliadača zapamätať zvolený svetlý, tmavý alebo automatický vzhľad a preferovaný jazyk.

Tieto údaje slúžia iba na zachovanie nastavení stránky. Nepoužívajú sa na sledovanie návštevníka ani na zobrazovanie reklamy.

Uložené nastavenia môže návštevník kedykoľvek odstrániť vymazaním údajov stránky vo svojom prehliadači. Web nepoužíva analytické ani reklamné cookies.

04 · EXTERNÉ SLUŽBY

Hosting a písma

Stránka je poskytovaná prostredníctvom služby GitHub Pages.

Pri načítaní externých písiem môže prehliadač nadviazať spojenie so službami Adobe Fonts alebo Google Fonts. Na tieto služby sa vzťahujú ich vlastné pravidlá ochrany súkromia.
